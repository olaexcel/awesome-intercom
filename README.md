# TradeBot AI – Agentic GameFi Auto Trading App

## 🧠 Overview
TradeBot AI is an agent-powered GameFi trading application built on
Trac Network Intercom.

It enables autonomous AI agents to negotiate, buy and sell in-game
assets on behalf of players using peer-to-peer communication.

Agents can:

- Detect BUY / SELL trade requests
- Find matching traders
- Open private negotiation channels
- Negotiate asset prices
- Execute TNK token payments
- Confirm asset delivery
- Log completed transactions

All trading actions can occur even when the player is offline.
